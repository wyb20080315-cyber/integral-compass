提前安装包；打开仓库 README 和终端，放大字体。联网不稳定时用已安装的本地版本，
不要在演示中临时下载依赖。先运行 `python examples/demo.py`，确认三例能完成。

## 问答

**是不是自己实现了 Risch？** 不是。我们使用 SymPy 的实现；自己完成课堂策略、
步骤组织、DI 表格、接口设计、验证、超时处理和软件交付。

**None 表示积分不存在吗？** 不是，只表示已证明没有初等函数形式的原函数。
例如高斯函数可以用 erf 表示原函数，也能做数值积分。

**为什么不直接用 SymPy？** SymPy 是通用系统，我们面向初学者组织课堂步骤，
并强制区分成功、已证明无初等解、未知三种情况。

**能处理任意函数吗？** 不能。支持规定的单变量表达式；不支持的情形明确返回 unknown。

**怎么判断答案对不对？** 对原函数求导，符号化简为输入；测试还在避开奇点的位置抽样检查。
这验证局部恒等式，不证明全局定义域。

**AI 做了什么？** 使用 OpenAI Codex 协助代码、测试和文档；团队需要审查、运行并理解交付物。
据实际参与情况介绍成员分工，不把 AI 的提交冒充为其他成员的工作。
