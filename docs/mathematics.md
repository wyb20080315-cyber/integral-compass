# Mathematics, attribution and limits

## DI is integration by parts

For a polynomial P of degree n and g with repeatedly available elementary
primitives G₁, G₂, …, repeated integration by parts gives

`∫P g dx = P G₁ − P' G₂ + P'' G₃ − … + (−1)ⁿ P⁽ⁿ⁾ Gₙ₊₁ + C`.

The remainder vanishes because P⁽ⁿ⁺¹⁾ = 0. The implementation constructs this
finite sum directly; it does not call a general integral solver for the DI path.
For `exp(a*x+b)` divide by a each time. For sine/cosine alternate the basis,
include the minus sign when integrating sine, and divide by a. Other DI cases,
including nonterminating cycles, are outside this strategy.

## Partial fractions

First use polynomial division `N/D = Q + R/D`, with degree R < degree D.
Over the rationals, `apart` decomposes using irreducible factors. Each repeated
linear factor `(x-a)^m` needs A₁/(x-a) through Aₘ/(x-a)^m; a repeated irreducible
quadratic needs a linear numerator for each power. SymPy performs the algebra
and integrates each term. High-degree irreducible denominators may need algebraic
root representations outside our expression language; those are not promised.

Rational functions possess elementary primitives, but a limited software package
may still return unknown when its representation or implementation is insufficient.

## Risch and the important third outcome

The Risch framework decides elementary integrability for specified differential
fields, subject to the relevant effective operations/constant-field assumptions.
It is not a promise about arbitrary functions, arbitrary programs, special
functions or finite computation time in this application.

We call SymPy's `risch_integrate(..., separate_integral=True)`. A
`NonElementaryIntegral` remainder is used as the backend's certificate that an
elementary antiderivative does not exist. That certificate is mathematical evidence
delegated to SymPy, not a full proof transcript generated by this package.

`NotImplementedError`, an ordinary unevaluated `Integral`, a special-function
answer, a nonzero/unresolved derivative check, a crash or a timeout do not prove
non-elementarity. They yield unknown unless another supported method succeeds.

The Risch backend currently supports exponential/logarithmic transcendental
extensions and is incomplete, particularly for trigonometric and algebraic extensions.
General SymPy fallback is accepted only for elementary expressions with verified
derivatives; it does not provide our own classroom derivation.

## Verification and domains

For elementary answers simplify `F' - f` symbolically and require zero.
For real `log(Abs(g))`, verification uses the identity `(log|g|)' = g'/g`
on intervals where real g is nonzero. It does not assert the identity at g=0.
Branch choices, singularities and disconnected intervals are not resolved globally.
The arbitrary integration constant is omitted by the API.
